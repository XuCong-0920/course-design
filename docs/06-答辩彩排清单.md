## 三、当天：只做三件事

1. **开录前**：清数据重启、开网、点一次「我的 → 清空在线词典缓存」（保证录屏里能看到联网出结果）、把系统通知权限开着。
2. **讲的时候**：按 `docs/04-录屏脚本.md` 的分镜顺序，不要临场发挥改流程；每页 PPT 停 10 秒以内。
3. **问答时**：先给结论（一句话），再指一处代码（文件 + 常量），最后说取舍代价。答不上来的直接说「这块是按 X 思路做的，具体参数我记在文档 §5.x」，不要硬编。

## 四、现场最可能被问的 8 个问题（配答案位置）

| 问题 | 一句话答案 | 指哪 |
| --- | --- | --- |
| 间隔怎么算的？ | 简化 SM-2，三档 q=2/3/5，间隔 1→3→round(旧间隔×EF)，夹在 1–180 天 | `SrsScheduler.schedule()` |
| 为什么答错只等 10 分钟？ | 同一次会话内给第二次机会，但不插回本轮队列 | `FORGOT_RETRY_MILLIS` |
| 数据存哪？ | Room 三张表，SRS 字段内嵌在 words 行内 | `WordEntity.kt` |
| 为什么复习要一个事务？ | 改 SRS 与插记录必须同生共死，否则统计与调度会互相矛盾 | `WordRepository.submitReview()` |
| 通知怎么做的？ | WorkManager 每日周期 + 三个 Action；到期为 0 不发 | `notification/ReminderScheduler.kt` |
| 联网用的是哪家？ | 有道 jsonapi（免费无 key）+ dictvoice mp3；缓存 7 天 | `DictionaryRepository` |
| 断网会崩吗？ | 不会，三层降级：在线区块提示失败、每日例句退回本机、缓存离线可看 | `DailySource.{ONLINE,LOCAL,OFFLINE}` |
| 测试为什么不让它影响记忆？ | 否则随手刷题就能把词刷到 180 天后，曲线失真 | `QuizBuilder` 不写库 |

## 五、兜底预案

- **模拟器起不来**：直接放录屏（要求里录屏是独立交付物），PPT 上指截图。
- **现场断网**：每日例句会自动降级，正好可以当作"降级设计"现场演示；发音按钮会说「发音需要联网」。
- **通知不弹**：先讲 `canPost()` 的三重判断（权限、系统开关、到期数为 0），再说明这是刻意不打断用户。
- **被问到没做的**：伴生模块的 AppWidget（P1 备选方案）还没做，方案写在 `docs/02-技术方案.md` §5.3 的后续计划里，如实说。
