# 需求与功能清单（主 App · B4 单词记忆）

> 用于第 1 次实验课「选题审核 + 功能清单 + 伴生模块设想」现场口头讲需求。

## 1. 用户与场景

- 用户：准备四六级 / 考研 / 专业课词汇的学生。
- 场景：每天碎片时间（5–15 分钟）打开 App，复习"今天该复习"的单词；新词先过一遍，之后按遗忘曲线自动安排到未来某天。
- 痛点：纸质单词书没有复习节奏；通用背单词 App 有强制联网、广告、词库不合用。
- 目标：**打开就知道今天该背哪些**，不用自己排计划。

## 2. 对照课程「最低复杂度标准」逐条说明

| 标准 | 本项目的落实 |
| --- | --- |
| ≥ 4 个界面，含「列表 → 详情」 | 6 个界面：词库列表 → 单词详情；今日复习；测试模式；学习统计；设置 |
| 数据持久化 | Room（`Word`、`Deck`、`ReviewRecord` 三张表）+ DataStore（提醒时间、每日上限等设置） |
| 至少一项硬能力 | **后台任务**：WorkManager 每日复习提醒；**通知**：Notification + 通知内动作 |
| 异步与生命周期 | 协程 + ViewModel + Flow；Room/文件导入全部在 IO 线程；列表用 `repeatOnLifecycle` 收集 |
| 权限申请与降级 | Android 13+ `POST_NOTIFICATIONS`；拒绝后不弹通知，改为 App 内红点 + 首页横幅提示，并引导到设置页开启 |
| 自定义业务逻辑 | **SRS 调度算法**（自定义实现，含单元测试）：根据用户三档反馈更新 `interval / easeFactor / nextReviewAt` |
| 加载态 / 空态 / 错误态 | 词库为空时显示引导卡片；导入失败显示错误行号与原因；复习队列为空显示"今日已完成" |

## 3. 功能清单（对应 README 的 F1–F5）

### F1 词库管理
- 词库列表：显示名称、单词数、今日待复习数；支持新建、重命名、删除（二次确认）。
- 单词 CRUD：手动新增 / 编辑 / 删除；必填校验（单词、释义非空）。
- 列表 → 详情导航；详情页展示例、复习历史（最近 5 次）。

### F2 词库导入
- 内置示例词库（约 100 词，附带首次启动导入）。
- 支持 CSV（`word,phonetic,meaning,example`）与 JSON 导入，通过系统文件选择器（SAF）读取。
- 容错：表头识别、空行跳过、坏行汇总提示（"成功 96 条，跳过 4 条"）。

### F3 每日复习队列
- `nextReviewAt <= now` 的单词进入今日队列；按到期时间升序。
- 卡片式复习：正面单词 + 音标，点击翻面显示释义与例句。
- 三档反馈：不认识 / 模糊 / 认识 → 分别按算法重新安排（见技术方案）。
- 每日上限（默认 50）可在设置中修改；队列为空时显示完成态与连续天数。

### F4 测试模式
- 选择题：给出单词，4 个释义选项（干扰项来自同词库）。
- 拼写题：给出释义与首字母，输入完整单词（忽略大小写与首尾空格）。
- 交卷页：正确率、逐题回顾、错词一键加入明日复习（`nextReviewAt = 明天`）。

### F5 学习统计
- 今日待复习 / 已复习 / 新增词数。
- 近 7 天复习量柱状图（自绘 Canvas，不引第三方图表库）。
- 连续学习天数（streak）：当日有 ≥1 条复习记录即算打卡。
- 正确率趋势：近 7 天测试正确率折线。

## 4. 非功能需求

- 离线可用：除导入文件外不依赖网络。
- 启动到词库列表 ≤ 1.5s（Room 预置数据量级 1k 词内）。
- 单次复习操作响应 ≤ 100ms；数据库写操作不阻塞主线程。
- 崩溃兜底：全局 `CoroutineExceptionHandler` + 关键页面错误态。

## 5. 伴生模块设想（1 学分）

**P3 通知提醒中心**
- 独立可运行：可从桌面图标或主屏快捷方式直接启动演示（一个"提醒中心"页面：下次提醒时间、开关、测试推送按钮）。
- 数据打通：只读主 App 的 Room 数据库，统计"今日待复习数"，写入通知内容。
- 强制技术点：WorkManager 周期任务 + Notification（含 Action：开始复习 / 稍后 10 分钟 / 今日免打扰）。
- 异常处理：通知权限关闭时页面内提示并给出开启入口；任务失败重试（`Result.retry()`）。

## 6. 验收演示脚本（3 分钟）

1. 新建词库 → 导入 CSV → 列表显示 45 词。
2. 进入今日复习 → 翻卡 → 三档反馈 → 队列减少 → 明日到期数增加。
3. 关闭再打开 App（重启进程）→ 复习状态仍在（持久化证明）。
4. 测试模式 5 题 → 交卷 → 错词进入明日复习。
5. 统计页 → 连续天数与 7 日柱状图更新。
6. 伴生模块：手动触发通知 → 通知栏点"开始复习"→ 直达复习页。
