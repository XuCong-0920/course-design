# 3 分钟录屏脚本与拍摄清单

> 交付要求：3 分钟以内，**界面必须带学号 + 姓名水印**，全程真实操作（不许剪接伪造功能）。

## 一、拍摄前 10 分钟准备

| 项 | 做法 | 检查点 |
| --- | --- | --- |
| 设备 | MuMu 模拟器或真机，1080p 以上 | 状态栏干净（关掉无关通知、开飞行模式避免弹窗） |
| 数据 | 设置里清空后重新启动 App，让它自动播种 22 个词 | 首页显示「B4 结课词表 12 词 / 四级高频 10 词」 |
| 待复习数 | 首页「今日待复习」应为 22（全新数据） | 复习页显示「还剩 22 个」 |
| 水印 | debug 包默认开启，右下角半透明两行：`202405100228 徐聪` | 每个界面都能看到，且不挡按钮 |
| 录屏工具 | Windows：`Win + Alt + R`（Xbox Game Bar）或 OBS；MuMu 内置录屏亦可 | 分辨率 ≥1080p、30fps、无鼠标抖动 |
| 声音 | 麦克风单独录，不要用外放环境音 | 录前试读 10 秒，确认没有回声 |

> 水印实现建议：`MainActivity` 里在 `BuildConfig.DEBUG` 为真时向根布局加一层不可点击的 `TextView`（`alpha=0.35`、右下角、`text="202405100228 徐聪"`），正式包自动不显示。这样不必为了录屏改布局。

## 三、收尾核对（录完必查）

1. 总时长 ≤ 3:00（超出就删 0:25–1:05 的详情段落，那一页 PPT 里也有）。
2. 每一帧都看得到水印；没有出现 Windows 任务栏、聊天窗口、Clash 界面。
3. 通知那一镜必须真的出现通知（没有就先去系统设置给通知权限）。
4. 文件命名：`202405100228_徐聪_B4单词记忆_演示.mp4`，与 PPT、源码一起交。

## 四、最容易翻车的四点

- **录到空态**：复习页显示的却是「本轮复习完成」——因为之前点过。录前务必清数据重启。
- **通知不出现**：Android 13+ 没给 `POST_NOTIFICATIONS`，或系统把它静音了。先点「立即发一条测试提醒」确认能弹出再开录。
- **水印盖住按钮**：水印放在**底部导航之上 8dp**，别压在「认识 / 模糊」那排按钮上。
- **声音与画面不同步**：先录屏、后配音更稳；现场答辩时才用「边说边操作」。
